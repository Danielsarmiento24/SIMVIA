# SIMVIA / Documentación

Esta rama reúne la documentación técnica y académica desarrollada para el proyecto **SIMVIA (Sistema Inteligente para el Monitoreo Vehicular)**.

Aquí se encuentran los documentos utilizados durante el desarrollo del proyecto, incluyendo la documentación final, los manuales técnicos y los archivos de apoyo empleados durante la elaboración del prototipo.

---

## Contenido de la rama

```text
docs/
├── Documento Final
├── Manual de Usuario
└──Especificaciones Técnicas

```

---

## Documentos principales

Esta rama incluye, entre otros, los siguientes documentos:

* **Documento Final del proyecto**, que describe el desarrollo completo del sistema SIMVIA.
* **Manual de Usuario**, con las instrucciones para la instalación, configuración y operación del prototipo.
* **Documento de Especificaciones Técnicas**, donde se describen las características de hardware, software y funcionamiento del sistema.

## Objetivo

El propósito de esta rama es centralizar toda la documentación del proyecto SIMVIA, facilitando su consulta, mantenimiento y distribución durante las diferentes etapas de desarrollo, validación y presentación del prototipo.
